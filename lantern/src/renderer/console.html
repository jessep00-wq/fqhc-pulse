Lantern

Starting…

Any folder of Markdown files. Open the same folder in Obsidian and the two stay in sync — Lantern writes plain notes with YAML frontmatter and nothing else.

Authenticates with the ANTHROPIC_API_KEY in your environment.

Shortcuts

Voice

Leave the piper fields empty to use your operating system's built-in voice. Speech recognition has no fallback: without a whisper binary, type instead of talking.

What Lantern may do

One prefix per line. Matched on whole words, so git log allows git log --oneline but never git push. Anything that chains commands, or that Lantern classifies as destructive, always asks — allowlisting cannot override that.
